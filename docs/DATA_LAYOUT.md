# 目录、恢复内容与数据边界

源码与工具分别位于源代码目录和工具目录，公开模型身份见资源目录中的模型清单。模型权重在服务器的模型目录单独准备，不参与仓库同步。

用户于二〇二六年十一月十四日改为公开代码托管仓库，保存必要实验数据和结果，以便服务器清空后恢复。真实模型密钥继续禁止同步。共享池、图片及商城恢复块属于获授权的实验同步范围；本地商城购买记录和未购买参考保持原来源标签，不代表现实个人消费。同步范围由忽略规则及资源目录的同步策略共同检查。

```text
src/agent/config/llm.example.json     # 可同步的无密钥连接模板
src/agent/config/llm.local.json       # 仅本机保留，被忽略
resources/
  model_manifest.json
  github_sync_policy.json
  webshop/
    source/                         # 必要商城源码及上游许可
    catalog_bundle/manifest.json    # 完整商品库和原索引的恢复清单
    catalog_bundle/chunks/*.part    # 每块最多六十四兆二进制字节，可同步
    catalog/                        # 项目内恢复出的运行副本，被忽略
  evaluation_base/
    manifest.json
    migration_provenance.json
    groups/<组键>/source.jpg
    groups/<组键>/target.jpg
    groups/<组键>/definition.json

    evaluation_inputs/<组键>/queries.json
    shared_memory/shared_memory.json # 一百八十九条共享记忆

  logs/
  <恢复状态与必要断点>

```

正式实验的成图、评分归档、向量证据、原始模型响应及恢复记录均可同步。模型权重、运行环境、可重建临时缓存、迁移旧档、本地测试工作子目录及重复副本排除。必要优化器状态不能仅因二进制扩展名而被排除。实际提交前运行同步检查，规则不会代替提交与推送动作。

商城数据包包含九十二份运行文件的无损压缩分块，原始总量八十六亿七千六百八十六万六千八百二十八字节，存储量二十九亿零一百八十八万二千九百八十八字节。恢复出的数据库、购物目标和原搜索索引都位于本项目内；旁边项目的旧绝对路径仅保留为构建来源证据，不是运行输入。完整目录包含商品图片网址，并不包含全商城图片本体；当前九组与共享池的冻结图片已实际保存。

公开选图默认直接只读投影恢复后的商品数据库，仅返回商品编号、公开名称和主图地址。此库是原始公开目录的规范化版本，不能宣称与重新扫描原始文本在所有边角格式上完全等同。搜索继续使用同一份原索引，不因迁移而重建。

生成端仅可读取公开图对、商品自身公开特点和标注，禁止读取共享池及正式请求。所有成图冻结后，评估端才能读取完整共享库并在副本中替换图片。分组只供审计，不能按组缩小候选池。真实购买与未购买参考来源标签不得混写。

本次保留九组冻结图对，第七组改为后期重选洗发水；第四和第八组的门槛例外仍明确记录。一百八十条正常记录和另八条源参考已经从完整原始池恢复，逐字段保持一致，包括历史诊断字段；仅第七条源参考换新。原始像素九组完整对照也已导入，默认直接复用。保全核对见迁移来源清单，旧项目保持只读。

服务器恢复后先运行完整资源预检，核对一百八十九条记忆、一百九十八张共享主图、一百八十条正式文字及绑定摘要。仅代码预检参数用于暂时缺输入的安装检查，不能代替正式实验的完整核验。
