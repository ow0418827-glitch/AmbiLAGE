# 当前方法及比较边界

仅公开 lucid（原始像素优化方法）与 ambilage（环境光背景协同调整及主体微光影方法）。二者复用同一份冻结公开图对和核心特点正文，生成不读取共享池、正式请求、正式名次或留出模型。

新方法四阶段为：

1. 根据源商品公开品类和图像亮度统计，使用确定性显式环境光配方生成光影协调计划（不再依赖大参数视觉语言模型）；`SAM2` 主体分割与 `RapidOCR` 识别联合局部中值滤波墨迹核心提取（`extract_ink_core_mask`），避免把彩色瓶身或金属漆误锁为墨迹，同时对高对比印刷文字核心严格锁死，并生成包含高光/深阴影衰减调制的双重空间包络（`w_fg_body` 与 `w_fg_recolor`）。
2. 从目标商品公开图片前景提取颜色统计（均值及分位数），准备背景谐调与平滑约束参数。
3. 在墨迹核心精确保护与双重掩膜保护（`compute_recolor_attenuation_mask` 保护纯白高光反光区与深暗部特征区）下，在可微 `OKLab` 色彩空间对商品主体非印刷表面执行“锁亮度 `L`、放色度 `(a, b)`”的颜色协调（`harmonization_chroma_transfer_strength=0.55`），同时将纯白背景平滑过渡至温和浅暖棚拍底色，经 32 步回溯线性搜索（`harmonize_illumination`）结合 `OKLab` 亮度结构相似性（SSIM）、亮度平均绝对误差（MAE）与亮度边缘光晕误差约束生成自然锚点（不再加载 34GB 扩散编辑全量模型），并将源原图印刷墨迹核心逐像素回写。
4. 在原生十六通道变分自编码器（FLUX `AutoencoderKL` `vae` 子目录）潜空间中联合优化：背景分支彻底取消逐像素 16 通道潜差分与 `8x8` 空间网格，替换为唯一可学习全局三维背景色向量 `bg_color_shift`（`[1, 3, 1, 1]`）叠加单自由度径向暗角轮廓，从数学结构上消除背景局部斑点；前景分支在 `OKLab` 空间严格约束亮度 `L` 偏移（`fg_luma_scale=0.40`），同时大幅放开全局与大核平滑色度 `(a, b)` 迁移（`fg_chroma_levels=64`、`fg_chroma_limit=0.16`），辅以平滑色度全变分惩罚（`fg_chroma_tv_weight=0.02`）与可微亮度边缘光晕抑制（`differentiable_halo`）。按显式方案选择训练代理，逐一计算图像梯度再回传潜变量；只优化公开完整检索键与唯一图文联合目标的相似度，覆盖模糊、压缩、缩放和十步全梯度扩散净化。最终通过基于 `OKLab` 亮度 SSIM、亮度 MAE、前景平滑色度 TV（`fg_chroma_tv_ceiling=12.0`）、边缘光晕与印刷核心零改动的严格数学自然度门禁；失败时只保存证据，禁止写完成凭证。全流程峰值显存约 10–12 GB，兼容 T4（16GB）、L4（24GB）与 A100（40GB）显卡。

按二〇二六年十一月十四日用户要求，独立纯文字训练目标已删除。设归一化运算为 $N$，目标商品图片向量为 $I_t$，冻结目标特点文字向量为 $T_t$，修改图片向量为 $I_x$，源商品自身真实公开文字向量为 $T_s$，唯一查询目标与候选键分别为：

$$q=N(I_t+T_t),\qquad k=N(N(I_x)+T_s).$$

图片与文字在各自联合表示中均各占一半；同时在 $q\cdot T_s > 10^{-4}$ 时通过解析方向补偿 $c = N(2(q\cdot T_s)q - T_s)$（混合权重 `compensation_weight=0.35`）减轻源公开标题文字与背景色造成的视觉竞争拖曳。每个代理通过初始锚点基线校准的相对增益软最小权重（`ensemble_temperature=0.20`、`ensemble_uniform_mix=0.45`）均衡各代理优化幅度，避免跨家族编码器初始余弦尺度差异导致的单代理偏向；图文联合效用整体权重默认一，所选代理集合加权、净化和空间正则保持协同。

当前方法配置不接受已删除的 `text_weight`（纯文字训练目标权重）字段，即便其值为零也会报错，避免旧配置被静默解释为新训练。该字段在原始像素方法中属于其原有文字对齐配置，两种方法的配置空间独立。生成审计使用新的目标版本，并只登记一种图文查询目标；旧双目标完成凭证不能作为当前成图复用，历史文件保留原记录。

训练只用上述公开图片和冻结特点正文。正式评估仍可选择纯文字或图文查询；评估模式不会改变训练目标，也不允许训练读取正式请求。

指定生产模型、训练代理和两个严格留出评估模型见资源目录的模型清单（`editor` 仅按 `vae/*` 模式拉取 16 通道 VAE 权重，`planner` 标记为可选 `optional`）。公开下载需要由服务器显式执行；运行阶段只加载本地权重。加载失败不能切换成随机网络、启发式模型或模拟编码器。

代理方案、命令参数及历史对照边界见 [训练代理选择说明](TRAINING_SURROGATES.md)。默认方案直接读取原始像素方法配置，不能只按架构名忽略同架构下不同预训练权重。

印刷核心零改动是相对源原图的实际像素约束。主体在 Stage 4 中对 `OKLab` 亮度通道 `L` 保持微光影锁定（`latent_levels=6`），同时允许在双重掩膜保护下通过全局与大核平滑色度 `(a, b)`（`fg_chroma_levels=64`）实现自然本体配色迁移；源图到自然锚点同样允许在亮度结构数学门禁下进行照明与色调协调。背景仅受全局三维颜色参数与一维径向暗角控制并受限于 `background_levels`。

对称可行区间、大核背景平滑、边缘光晕正则与空间包络用于减少截断及杂色伪影，最终外观由显式线性搜索锚点与确定性数学门禁共同把关；须保留失败案例，不根据正式排名重采样或改图。

扩散净化使用冻结噪声网络及确定性隐式逆过程，是项目中的指定净化条件，不冒充其他完整防御论文的精确复现。压缩期望变换保留实际压缩前向，反向使用明确记录的可微代理。两者具体路径均记入生成审计。
