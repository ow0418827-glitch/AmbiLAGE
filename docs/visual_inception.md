# 视觉记忆植入攻击基线

本项目将 Visual Inception(视觉记忆植入攻击)作为独立比较基线，方法标识为 `visual_inception`(视觉记忆植入攻击方法标识)。它直接优化源商品图片的像素扰动，与环境光协同方法分别生成、记录和冻结。本实现按用户要求省略记忆库检索损失，复用来源项目由公开商品特点构造的三条购买意图模板，不能作为论文全部实验设置或论文报告数值的严格复现。

原文依据为[论文第 3.1、3.2 节及附录](https://arxiv.org/html/2604.16966v1)。原论文使用目标语义、记忆库检索和感知差异三个损失；本项目实现仅保留目标语义与感知差异。论文中的困难负例以及额外查询增强未给出完整可执行定义，本实现不另行补造这些算法。

## 优化目标和默认参数

设源图片为 \(I\)，扰动为 \(\delta\)，三条公开训练文字为 \(q_1,q_2,q_3\)，代理编码器为 \(E_i\)。本项目计算：

\[
L_{\mathrm{sem},i}=\frac{1}{3}\sum_{j=1}^{3}\left[1-\cos\left(E_i(I+\delta),E_i(q_j)\right)\right]
\]

\[
L=\sum_iw_iL_{\mathrm{sem},i}+0.1\operatorname{LPIPS}(I,I+\delta).
\]

其中 LPIPS(学习感知图像块相似度)使用真实预训练 AlexNet(亚历克斯卷积网络)骨干及学习到的线性校准权重。语义项权重固定默认值为 1.0，感知项默认值为 0.1。查询模板直接形成语义目标是本项目适配：省略检索损失后，没有另设一个形式上声称使用查询、实际上不产生梯度的模块。

| 参数 | 默认值 | 说明 |
|---|---:|---|
| 优化步数 | 100 | 完整执行指定日程，保存最终步 |
| 最大单像素扰动 | 8/255 | 对源图片执行无穷范数投影 |
| 每步步长 | 2/255 | PGD(投影梯度下降)更新 |
| 语义项权重 | 1.0 | 三条公开模板的平均余弦距离 |
| 感知项权重 | 0.1 | 真实感知网络的可微距离 |
| 梯度方差估计 | 10 次随机重启 | 冻结种子，记录估计及归一化模型权重 |
| 随机种子 | 42 | 同一配置与数值运行时使用同一随机来源 |
| 训练代理 | 独立论文三代理方案 | 大型图文对比、缩放图文对齐及大写巨型图文对比模型；原始像素方法默认不变 |

原文没有完整规定梯度方差的归约、随机起点采样和数值稳定细节。本项目从像素预算内均匀抽取十个随机起点，仅用其语义输入梯度估计各代理的不确定性：先计算每个像素梯度的总体方差，再对像素与通道取平均；代理权重取该方差的倒数平方并归一化，在正式优化开始前冻结。数值下限采用相对方差尺度，避免梯度很小时所有代理退化为等权；这些实现假设写入运行记录，不能称为作者完整实现。十个随机起点只用于估计权重，随后从干净源图片开始执行一次完整优化，不进行多次成图后挑选结果。目标图片只用于冻结图对身份核验，不构成额外的图像对齐目标。

用户于二〇二六年十一月十六日要求该方法独立采用论文三代理，默认方案现为 `visual_inception_paper`(视觉记忆植入论文代理方案)，配置见 [独立三代理配置](../src/visual/config/surrogates.visual_inception.json)。原始像素方法保留原有三代理，环境光协同方法的默认代理也不受本次变更影响。

| 论文名称 | 实际注册结构 | 冻结预训练身份 |
|---|---|---|
| CLIP-ViT-L/14(大型十四分块图文对比编码器) | ViT-L-14(大型十四像素分块视觉变换器) | openai(官方图文预训练版本) |
| SigLIP-SO400M-patch14-384(约四亿参数、十四分块、三百八十四像素输入的图文对齐编码器) | ViT-SO400M-14-SigLIP-384(对应的官方图文对齐结构) | webli(网页图文预训练版本) |
| OpenCLIP-ViT-G-14(开放式大写巨型十四分块图文对比编码器) | ViT-bigG-14(官方注册的大写巨型十四像素分块视觉变换器) | laion2b_s39b_b160k(公开二十亿图文集预训练版本) |

论文写的大写巨型名称不是软件库的直接注册名，本实现按[官方注册表](https://github.com/mlfoundations/open_clip/blob/main/src/open_clip/pretrained.py)映射到大写巨型结构；它与本项目严格留出的小写巨型结构不同。论文没有给出精确检查点和权重文件摘要，因此这里冻结公开可获取的预训练身份，不声称与作者权重逐字节一致。配置、实际模型、预处理和摘要须核验后才能登记生产成图；微型夹具不宣称已运行真实论文代理。严格留出编码器仍禁止训练，切换代理必须使用新的输出目录，旧配置与旧结果保留原身份。

准备和预检时须显式选择该方案，以下命令默认只列出计划或核验信息，不装载模型；下载权重需在服务器另加下载开关，默认使用大陆镜像：

```bash
python -B -X utf8 tools/prepare_models.py --scope encoders --surrogate-set visual_inception_paper
python -B -X utf8 tools/preflight.py --code-only --surrogate-set visual_inception_paper
```

通用准备工具省略方案时仍沿用原始像素默认三代理；本方法生成入口及方法配置则默认使用上述论文方案，避免改变原始像素方法的已有行为。

## 公开训练文字的来源

三条模板复用来源项目的公开商品特点转换规则，模板填入目标商品公开品类及经过审核的特点。品类和特点来自冻结图对定义或其相邻的公开选图记录，不读取共享记忆、正式查询、正式名次或购物轨迹。

本实现只使用三条有来源的文字，不将重复文字凑成一百条，也不声称采用了原文的百分之五十商品描述、百分之三十模型改写、百分之二十留出日志抽样方案。训练文字会连同模板来源及摘要写入运行记录，保持可检查性。

## 依赖和本地权重

先按[远程部署说明](REMOTE_DEPLOYMENT.md)准备现有运行环境，再按需安装独立依赖。普通软件包优先使用大陆镜像：

```bash
python -m pip install -r requirements/requirements-visual-inception.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

本基线使用现有视觉库构建 AlexNet(经典卷积神经网络)结构，按官方零点一版公式计算感知距离，无需额外安装感知距离软件包。该骨干加零点一版是[感知度量官方默认配置](https://github.com/richzhang/PerceptualSimilarity/blob/master/lpips/lpips.py)，属于同一种度量的具体配置，不是用另一种损失替换感知度量。可访问论文原文只写度量名称，未给出骨干和版本，故不能确认作者采用的是不是同一默认配置。它装载真实 ImageNet(大型图像分类数据集)预训练骨干和官方线性校准权重，执行对应归一化、五层特征差异与校准加权；生产运行不会把未加载权重的网络用作正式感知损失。当前代码尚未完成真实预训练状态下与官方实现的数值及输入梯度对照验收。公式及权重来源参见[感知距离作者仓库](https://github.com/richzhang/PerceptualSimilarity)。

感知网络的两份权重必须事先准备到本地，默认位于模型目录下的 `lpips/alexnet-owt-7be5be79.pth`(预训练骨干权重相对路径)与 `lpips/alex_v0.1.pth`(官方线性校准权重相对路径)。也可以在配置中指定 `lpips_backbone_weights`(感知网络骨干权重路径)和 `lpips_linear_weights`(感知网络校准权重路径)。显式相对路径按项目根目录解析。装载骨干时核对发布文件名中的官方摘要前缀，装载校准权重时核对完整官方摘要，并将两份实际文件的完整摘要写入完成凭证。训练入口不自动下载；缺少文件、摘要不符或校准结构不完整时停止，不以随机感知网络或像素均方差替代。

文件来源为[视觉模型库官方预训练骨干](https://download.pytorch.org/models/alexnet-owt-7be5be79.pth)与[感知距离作者发布的校准权重](https://raw.githubusercontent.com/richzhang/PerceptualSimilarity/master/lpips/weights/v0.1/alex.pth)。后者下载到本地后命名为 `alex_v0.1.pth`(本项目校准权重文件名)。模型根目录默认是项目内的 `models`(本地模型目录)，也可通过 `AMBILAGE_MODEL_ROOT`(模型根目录环境变量)显式指定；本地模型目录不纳入代码同步。

## 生成、冻结和评估

通过 `--method visual_inception`(选择视觉记忆植入攻击方法)调用新基线，通过 `--visual-inception-config`(视觉记忆植入攻击配置路径参数)传入独立配置。源图、目标图和特点须与同一冻结图对一致。输出目录只归当前方法所有，已有完成凭证的目录禁止覆盖。九组公共基础包推荐使用下面的统一实验命令；该命令只从公开资料补齐目标商品的真实品类和特点，避免把图对的宽泛分组名称误当成商品品类。

```bash
python -B -X utf8 tools/run_experiment.py generate \
  --group 07_shampoo \
  --method visual_inception \
  --visual-inception-config src/visual/config/visual_inception.example.json \
  --output output/visual_inception_trial \
  --device cuda
```

上例先生成第七组；将组参数替换为全组取值即可串行生成九组。按实际本地权重位置调整配置；使用默认位置时可以省略配置参数。长耗时远程任务按[远程部署与验收](REMOTE_DEPLOYMENT.md)规定脱离伪终端、断开标准输入并持久化日志。

较底层的统一图片命令同样支持新基线，但传入的公开定义必须含有目标商品真实品类、公开特点和已冻结的规范句。旧基础包中的宽泛分组字段不足以直接充当这些输入，推荐使用上面的实验入口解析完整公开资料。

九组流程继续沿用现有公共基础包：全部九组新基线图片完整生成并冻结以后，才允许进入正式评估；在同一个完整共享库的评估副本里同时替换九条检索图片。完整原库保持只读，真实购买与未购买参考标签保持真实。正式纯文字与图文查询仍须显式指定，缺少正式查询图片时停止。

完成凭证绑定输入和输出图片摘要、公开训练文字、实际完成步数、像素预算、代理配置与权重身份、感知网络证据及明确删除的检索损失。修改设置或实现须使用新目录，不能改名复用旧环境光或原始像素成图。

## 本地微型验证边界

`--smoke-test`(显式微型测试模式)仅允许中央处理器、至多三步以及长边不超过六十四像素的合成图片。微型代理和微型感知距离只用于验证接口、梯度、投影、随机种子、完成凭证和访问边界，全部产物标记为测试夹具，禁止正式冻结或评估。

```bash
python -B -X utf8 -m pytest src/tests/test_visual_inception.py
```

本地测试结果不能说明真实模型兼容性、显存、速度、视觉自然度或攻击效果；这些结论须来自服务器真实模型运行与冻结后的独立评估。
