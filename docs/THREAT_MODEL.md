# 暂定黑盒威胁模型

攻击者只能修改自己有权发布的商品图片，不修改商品名称、品牌或其他商户商品。模拟可控公开商品集合不自动证明真实商家所有权。

公开图对选取和生成只使用公开商品图片、自身公开名称、经核对的品牌及特点、公开标注和公开训练代理。不读取受害记忆、未来正式询问、私有平台类目或正式检索名次，不以探测平台来挑选商品、图对、种子或最终成图。

两个公开方法使用同一份冻结图对和目标特点训练正文。新方法还使用源商品自己的完整公开检索键，这些字段独立取自公开元数据，不从共享池反向复制训练信息。两个留出评估模型不进入训练代理列表。

全部待比较图片完整生成并冻结后，评估端才读取共享池和正式请求。基础共享池只读，评估副本只替换指定源商品的检索图片；商品真实名称、特点、来源和购买事实不变。任何请求检索全部一百八十九条，不建立按组小库。九条源参考未观察到购买，不能写成真实购买记录。

记忆键由商品图片及其真实名称、确认品牌、特点正文和属性等权构成，排除操作轨迹。完整购买历史只用于召回后展示与审计。查询模式显式指定：纯文字只编码正式文字；图文模式使用独立生成并经过视觉核对的无品牌查询照片，图文各半，缺图时停止。当前自包含基础包附的是二十条一组的特点纯文字询问，没有附可直接使用的独立查询照片。图片不能回退为源图或目标原图。

同组两方法复用同一份正式请求。正式询问与特点训练正文的精确重合须如实报告，不能据此宣称完全未见语义。现有基础包每组有一条规范化精确重合，实际计数绑定在询问清单中。

防御统一作用于原图库和修改库的全部记忆图片，查询图片保持原样。独立重编码与候选分数复算验证前三、前五和同轮增量。召回比例不等于误购率。购物默认为关闭的独立适配接口，本次迁移未恢复旧实验或调用购物模型。

独立模型身份隔离不能证明对任意未知现实系统的有效性；本地微型测试也不能证明真实模型的自然度、鲁棒性或显存表现。公开筛选的灰度特征并非严格的物理拓扑描述；历史第四、第八组的门槛例外保留且明确披露。

文件访问审计用于复现检查，不是防恶意代码的操作系统沙箱。现实平台可观测接口、攻击预算和所有权假设仍须在正式研究中完整界定，迁移本身不构成黑盒攻击有效性实验。
