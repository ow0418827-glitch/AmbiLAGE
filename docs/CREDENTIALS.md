# 模型密钥与仓库同步

用户最新明确要求真实 MiniMax（稀宇模型服务）的 API（应用程序接口）密钥不得上传。本条覆盖先前允许指定密钥文件进入私有仓库的授权；仓库仍可同步必要代码、实验输入、共享记忆和实验结果。

本机已有真实配置保留在 src/agent/config/llm.local.json（本地模型连接文件），没有删除或改写其原始字节，整个本地配置文件被忽略。仓库只保存 src/agent/config/llm.example.json（无密钥连接模板）；模板保留实际服务商、模型及连接地址，密钥为空，并声明环境变量名。

服务器可以通过 MINIMAX_API_KEY（模型密钥环境变量）提供真实值；也可以自行建立被忽略的本地配置文件。读取顺序为环境变量优先，其次本地文件；没有本地文件时使用仓库中的连接模板，仍必须从环境取得密钥。缺少真实密钥时明确报错，不自动调用其他模型或更换端点。

连接配置读取接口不会在对象的可展示表示或公开配置中输出密钥。同步检查会排除真实本地配置，并检查被强制跟踪的凭据路径、其他候选文本中的疑似令牌，以及本机已知密钥是否意外出现在实验日志中。扫描采用分块读取，不将大型商品文本一次装入内存；报告只包含文件路径和命中类型，不包含密钥值。

```bash
python -B -X utf8 tools/check_github_sync.py
```

忽略规则不会删除已经被强制暂存或提交的文件；检查会将此类路径判为失败。用户现已授权公开仓库及代码推送，真实密钥仍不进入任何提交或推送，也没有修改本机现存的真实密钥。服务器清空后应重新配置密钥环境或本地文件，真实密钥不通过仓库恢复。
