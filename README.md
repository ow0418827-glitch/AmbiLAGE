# AmbiLAGE（环境光协同商品图像编辑项目）

公开方法包括 lucid（原始像素优化方法）、ambilage（环境光背景协同调整及主体微光影方法），以及 visual_inception（视觉记忆植入图片扰动基线）。三种方法共用冻结公开图对和公开特点；来源项目保持只读，当前运行不依赖来源目录或其输出。

视觉记忆植入基线按用户要求省略记忆库检索损失，复用来源项目已有的三条购买意向模板，用文字语义对齐与真实感知损失进行像素投影优化。默认一百步、步长二除以二百五十五、预算八除以二百五十五；独立默认采用论文的大型图文对比、缩放图文对齐和大写巨型图文对比三代理，冻结实际公开权重身份。该版本明确记录与原论文的差异，单独保存成图及完成证据，见[实现边界与运行说明](docs/visual_inception.md)。

环境光协同方法训练只使用图文联合目标：目标商品图片与冻结特点文字各半，候选检索键仍由修改图片与源商品自身真实公开文字各半构成。独立纯文字训练损失及其权重配置已删除；正式评估仍可显式选择纯文字或图文模式。方法说明与公式见 [训练目标](docs/METHOD.md)。

原始像素方法保持原有三代理，环境光协同方法默认继续共用其配置及装载器；视觉记忆植入基线使用独立论文代理方案，准备和预检时显式选择同一方案。命令参数可切换备选组合或项目内自定义模型列表，切换后使用新的成图目录。模型准备、预检和成图冻结使用同一选择，见 [训练代理选择说明](docs/TRAINING_SURROGATES.md)。

本地迁移和验证只使用微型合成图片、显式模拟后端和离线模型调用契约；没有下载或加载真实大型权重，没有执行全库防御循环。当前默认流程（Choice 1）已移除 Qwen2.5-VL 规划模型及 34GB FLUX 扩散骨干，`editor` 仅按 `vae/*` 拉取十六通道变分自编码器（约 335 MB），适配 T4（16GB）/ L4（24GB）/ A100（40GB/80GB）显卡。真实模型兼容性、自然度、速度和显存峰值仍需在远程 CUDA（图形处理器计算平台）环境实际验收。

仓库同步范围包括源码、无密钥配置模板、九组公开图对、正式请求、一百八十九条共享记忆及一百九十八张共享主图、正式生成图片、实验结果、全候选分数、必要向量证据、恢复状态及断点，以及完整商城目录的恢复数据块。真实连接文件 `src/agent/config/llm.local.json`（本地模型服务配置文件）仅在本机保留并忽略；服务器通过环境变量或被忽略的本地文件配置密钥，详见[密钥配置说明](docs/CREDENTIALS.md)。

模型权重目录、运行环境、可重建临时缓存、迁移旧档、测试临时工作目录和重复副本继续忽略。实验优化器状态等必要二进制文件不会仅因扩展名被排除；根验证报告也可以同步。具体规则见 [同步策略](resources/github_sync_policy.json) 和 [.gitignore](.gitignore)。

## 远程运行

详见 [远程部署与恢复说明](docs/REMOTE_DEPLOYMENT.md)。服务器克隆仓库后，独立安装环境和准备模型权重：

```bash
bash tools/setup_runtime.sh
.venv/bin/python -X utf8 tools/prepare_models.py --scope all --download
.venv/bin/python -X utf8 tools/preflight.py --hardware --require-models --output output/deployment/remote_preflight.json
```

下载默认优先大陆镜像，可显式指定官方源。`--scope all` 自动排除已停用的 `optional` 视觉语言大模型，且 `editor` 仅按 `vae/*` 模式拉取十六通道变分自编码器权重；`resources/model_lock.json`（模型恢复锁定清单）记录已准备模型的实际提交与文件摘要（可选历史扩展包见 `requirements/requirements-optional-vlm.txt`）。服务器清空后优先按锁定版本核验重新下载；新增锁定结果须随实验状态提交。生成模型按阶段加载和释放；缺真实权重时停止，不使用随机网络冒充生产成图。完整生成必须经过显式公开品类配方规划、Stage 3 三十二步线性搜索几何/颜色锚点、Stage 4 十六通道载体及大核背景平滑细化、印刷区墨迹保护及 `SSIM`/`MAE`/光晕数学门禁。所选训练代理与两个留出评估器严格分开，正式评估重编码且在独立进程复算完整候选分数。

[基础包清单](resources/evaluation_base/manifest.json) 绑定九组图对、一百八十九条记忆及一百八十条正式文字；第四、第八组保留历史外形门槛未通过的真实状态。共享池仅供成图冻结后的评估，恢复到同一仓库不会赋予训练读取权限。真实购买与未观察到购买的来源标签保持真实。

商城适配及策略接口默认不调用。完整商城必要源码、原始搜索索引及一百一十八万一千四百三十条商品目录已经迁入项目；在服务器运行 `python -m src.webshop.bundle restore`（商城数据恢复命令）即可从仓库内数据块恢复，不读取相邻旧项目。只有最终购物需要额外安装搜索运行时和英语模型，见[商城运行说明](docs/WEBSHOP_RUNTIME.md)。当前九组生成和检索不依赖完整商城；重新选图需要恢复数据库，新商品图片仍从公开网址下载。

当前九组直接复用已完成的八级扰动、完整千步原始像素成图，不再训练固定对照；后续主要生成新环境光协同方法。第七组已换后期新洗发水，正常一百八十条记忆完整保留。两方法各自九张图全部冻结后，同时替换同一个完整共享库中的九条源参考；向量仅在实际内容或编码身份变化时更新。执行命令与边界见 [九组及共享池复用说明](docs/SHARED_POOL_REUSE.md)。
