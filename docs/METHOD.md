# 当前方法及比较边界

仅公开 lucid（原始像素优化方法）与 ambilage（环境光背景协同调整及主体微光影方法）。二者复用同一份冻结公开图对和核心特点正文，生成不读取共享池、正式请求、正式名次或留出模型。

新方法四阶段为：

1. 仅根据源公开商品图和自身公开品类规划编辑指令；大型主体分割与文字识别联合提供主体和印刷保护区，生成余弦空间包络。
2. 从目标商品公开图片前景提取颜色统计，准备协调参数。
3. 在印刷核心保护下协调颜色，使用真实图像编辑模型生成自然锚点，并将源原图印刷核心逐像素回写。
4. 在真实十六通道变分自编码器潜空间中联合优化主体微光影、全局环境光与八乘八平滑光场。四个异构训练代理逐一计算图像梯度，再回传潜变量；只优化公开完整检索键与唯一图文联合目标的相似度，覆盖模糊、压缩、缩放和十步全梯度扩散净化。最后通过自然度门禁，失败时只保存证据，禁止写完成凭证。

按二〇二六年十一月十四日用户要求，独立纯文字训练目标已删除。设归一化运算为 $N$，目标商品图片向量为 $I_t$，冻结目标特点文字向量为 $T_t$，修改图片向量为 $I_x$，源商品自身真实公开文字向量为 $T_s$，唯一查询目标与候选键分别为：

$$q=N(I_t+T_t),\qquad k=N(N(I_x)+T_s).$$

图片与文字在各自联合表示中均各占一半；目标特点文字仍参与联合向量，不再额外计算 $k$ 与 $T_t$ 的纯文字目标损失。每个代理只返回一列联合余弦分数 $k\cdot q$，在变换条件上继续结合均值与平滑最小值；图文联合效用的整体权重默认一，四代理加权、净化和空间正则保持原流程。

当前方法配置不接受已删除的 `text_weight`（纯文字训练目标权重）字段，即便其值为零也会报错，避免旧配置被静默解释为新训练。该字段在原始像素方法中属于其原有文字对齐配置，两种方法的配置空间独立。生成审计使用新的目标版本，并只登记一种图文查询目标；旧双目标完成凭证不能作为当前成图复用，历史文件保留原记录。

训练只用上述公开图片和冻结特点正文。正式评估仍可选择纯文字或图文查询；评估模式不会改变训练目标，也不允许训练读取正式请求。

指定生产模型、训练代理和两个严格留出评估模型见资源目录的模型清单。公开下载需要由服务器显式执行；运行阶段只加载本地权重。加载失败不能切换成随机网络、启发式模型或模拟编码器。

印刷核心零改动是相对源原图的实际像素约束。主体六级微光影预算是相对第三阶段自然锚点的最终优化幅度，源图到自然锚点允许更大的生成变化；不能将其描述为全流程相对源原图最多六级。背景预算同样作用于最终协同细化阶段。

对称可行区间、平滑和空间包络减少截断及局部不连续风险，并不构成视觉无斑块、无光晕或不失真的数学保证。实际图像质量依赖生成模型及视觉门禁，须保留失败案例，不根据正式排名重采样或改图。

扩散净化使用冻结噪声网络及确定性隐式逆过程，是项目中的指定净化条件，不冒充其他完整防御论文的精确复现。压缩期望变换保留实际压缩前向，反向使用明确记录的可微代理。两者具体路径均记入生成审计。
