# 最近实验输入的直接复用

二〇二六年十一月十三日按用户追加要求更新。活动基础包仍位于资源目录中的九组评估基础包，后续生成和评估直接使用本项目独立副本，不读取来源项目运行。

共享池继续一百八十九条：一百八十条正常背景记录和九条源商品参考。正常记录从来源原始完整池恢复，包含此前规范化迁移省略的诊断字段；一百八十条正常记录逐字段完全一致，另八条未更换源参考同样完全一致。只有第七条源参考更换为商品编号 B09B63YYCW 的真实洗发水，目标仍为 B00BDJODWI。新源参考仍明确未观察到购买，没有套用旧商品购买轨迹。

第七组采用后期实际重选并完成原始像素对照的同一冻结图对，复制原商品和目标商品的原始字节、主体掩码、印刷区标注、特点和实际视觉核对证据。新旧目标属于同商品，后期文件编码摘要不同，但当时记录的实际像素差为零；这里保留后期冻结字节，以严格匹配可复用的对照成图。其余八组图对未重新选择。第四组和第八组历史外形门槛例外保留真实状态。

原共享图片目录的一百九十七张图片全部保留，新增新源原图一张后为一百九十八张。旧源图片没有删除，避免破坏历史审计引用；活动第七条记录已经唯一绑定新源图片。九组各二十条正式询问、目标特点训练正文均保持原字节或原正文，不根据名次修改。

完整保全核对见基础包内的迁移来源记录：每条正常记录保存完整对象的规范化内容摘要，来源池与后期原图库也绑定摘要。旧历史追踪中的原机器路径保留为原始审计文字；当前检索图片入口使用本项目自己的主图路径及摘要，运行不应追随历史模型载荷中的旧地址。

后续方法生成应只更新评估副本中对应源参考的检索图片及该图片相关向量。一百八十条正常记录无需改写。能否直接复用旧向量还必须满足编码器权重、分词器、预处理、图片、文字和融合模式身份一致；不同评估模型的旧向量不能冒充新模型向量。完整全局库及独立复算要求保持。

刷新工具只在用户明确指定来源目录时执行只读复制，不进行选图、生成、真实模型加载或检索排名。正常运行不需要来源目录存在。旧目标副本的被覆盖文件保存在迁移旧档目录，不进入活动实验入口。
