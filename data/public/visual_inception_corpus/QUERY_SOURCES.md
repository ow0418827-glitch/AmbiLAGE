# 独立公开检索查询的真实来源

正式准备输入位于 `data/public/visual_inception_inputs_v5`。八组各有二十条，共一百六十条完整查询；理发椅组仅冻结十二条，仍缺八条，必须停止该组的完整训练包准备，不得用重复、改写、普通椅子、洗头椅或合成句补足。顶层 `heldout_query_preparation.json` 的 `complete` 保持假值。

每条文字保留公开语料原文。品类归属使用预先声明的词法规则；独立固定种子四十二按文字摘要排序选取，不使用本项目正式询问、检索名次、共享记忆、模型训练表现或攻击表现。保留原始查询编号、真实来源分区和出处证据。筛除配件、其他品类、食谱、操作问答、维修、创业和沙龙服务等表达。微软来源是公开真实网页搜索语料，不能称为亚马逊购物日志。

上述摘要均采用 SHA-256（安全散列算法二百五十六位）。第二个来源还核对了官方公布的 MD5（消息摘要算法第五版）值 `519c5f522294406e3b0574d7d53cf233`。官方来源地址、真实字节数、版本与摘要另保存在各来源的 `snapshot_manifest.json`。

六个完整组采用亚马逊查询：监控摄像头、窗帘、牛仔裤、洗发水、音箱、牙刷。曲奇面团、接发两组采用微软公开点击分析搜索资源中的商品相关原始查询，二十条均独立选取；不能把这些网页搜索句称为模型改写。

理发椅组将三个真实来源按规范化原文合并去重，相同句只算一次并保留多源证据。最终十二条均可在微软保留的原始行摘录中定位；“barber chairs”另有亚马逊原始训练查询佐证，“barber chair”另有公开点击分析搜索资源佐证。二十条网页搜索候选中的八条被剔除，原文、编号、行号和原因保存在 `02_chair/query_exclusions.json`；其中洗头椅、牙科椅、办公椅和租赁税务查询均不纳入理发椅查询。

前两个来源的完整原始查询文件已保存，可以离线核对。第三个来源没有保存完整原流，不能声称可离线独立重算其全流摘要；目前只能离线核对二十条真实摘录及已记录的摘要。摘录中 `raw_source_record` 去掉行尾回车换行，而 `source_record_sha256` 对应原始行字节去掉换行后、保留回车的摘要。当前十二条接受查询已逐一核对原行和原行摘要。

需要重新在线获取并核验第三个完整原流时，使用下面的显式命令。它不下载文档或相关性标签，核验固定全流大小、行数和摘要，然后核验摘录摘要；不会将完整搜索原流写入磁盘。

```powershell
python tools/prepare_visual_inception_queries.py --rebuild-websearch-subset data/public/visual_inception_corpus/msmarco_websearch_rebuilt
```

`query_original_text_verification.json` 记录最终一百七十二条保存查询的原文归属核验：一百二十条逐项匹配亚马逊原始训练分区，四十条匹配完整微软公开点击分析搜索资源，十二条匹配网页搜索原行摘录。完整协议仍是每组二十条；保存一百七十二条不等于九组均已准备完成。

当前目录中的其他先前选择版本与诊断摘录不作为完整训练输入；正式训练只消费经过独立冻结与校验的训练包，理发椅数据缺口保持显式失败。
